H&E Slide Harmonizer

Reference-based color normalization for H&E image patches. An exploratory visualization tool—not a validated diagnostic pipeline.

Source repository

Normalize an image patch

Choose an input image and a representative H&E reference. Processing happens entirely in this browser; images are not uploaded to a server. Supported: PNG, JPEG, WebP. Maximum file size 20 MB each.

Uses mean and standard deviation matching in CIELAB (Reinhard-style). Excludes near-white background. This is not Macenko/Vahadane decomposition or whole-slide image processing. Images are downsampled to at most 1400 pixels on the longest side.
